# clickToBook
Este sera mi proyecto Fin de Grado para Ingenieria Informatica en la Universidad de Castilla-La Mancha. El titulo de dicho TFG es: Development of an Application that Integrates Intelligent Business Processes for the Management of Customer and Entrepreneur Meetings

# Instrucciones

Descargar repositorio. 

## arrancar el backend.
    - ir al directorio Backend. cd ./backend
    - nodemon app.js
Con esto se arranca el Backend. 

## arrancar el frontEnd.
    - nueva terminal
    - ir al directorio frontend. cd ./frontend 
    - npm install
    - ng serve 
Con esto arranca el FrontEnd
